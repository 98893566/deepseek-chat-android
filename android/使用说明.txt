DeepSeek Chat 安卓版 1.9.0 · 安装与使用
=====================================

文件：DeepSeekChat.apk（约 2 MB，支持 Android 8.0 及以上）

一、安装 / 升级
1. 用手机「文件管理」打开：下载/DSH-Go/DeepSeekChat/DeepSeekChat.apk
2. 如果提示「禁止安装未知应用」，点“设置”→ 允许来自此来源的应用 → 返回继续安装。
3. 已装过旧版的直接覆盖安装，对话记录保留。
4. 桌面图标「DeepSeek Chat」，点开是独立应用窗口。

二、首次使用
- 打开后进入“设置 → 数据管理”，填 API Key（官方 Key 在 platform.deepseek.com 创建）。
- 对话和附件保存在手机本地，发送时才请求你设置的接口地址。

三、接中转站
1. 设置 → 数据管理 → 接口地址，填入中转站地址，点“确定”。
2. 再填中转站给的 API Key。
3. 地址支持这几种写法（末尾不用加斜杠）：
   - https://api.deepseek.com        官方（默认）
   - https://your-relay.com          按 DeepSeek 结构，自动使用 /anthropic/v1
   - https://your-relay.com/anthropic
   - https://your-relay.com/v1       中转站直接暴露 Anthropic /v1
   直接粘贴到 .../v1/messages 也能识别。
4. 要求：中转站需兼容 Anthropic Messages 接口，并允许浏览器跨域访问（CORS）。
   只提供 OpenAI /v1/chat/completions 的中转站暂时不能直接用。
5. 换回官方：点“恢复默认地址”，再重新填官方 API Key。

四、上下文压缩（1.2.0 新增）
1. 对话页右上角点「压缩」。
2. 应用会把较早的对话交给模型总结成一段摘要；之后发送时只带“摘要 + 最近一轮”，
   不再重复发送全部历史，长对话能省下大量 token。
3. 至少要有 2 轮完整对话才能压缩；正在生成回复时按钮不可用。
4. 压缩后消息列表顶部会出现提示，可以：
   - 「查看摘要」展开看总结内容
   - 「恢复完整上下文」删除摘要，之后重新发送全部历史
5. 摘要保存在手机本地；导出的历史 ZIP 不包含摘要。
6. 压缩本身会调用一次模型（对话很长时会分段多次调用），会产生少量费用。

五、删除 AI 回复（1.3.0 新增）
1. 最后一条 AI 回复下方有一排操作按钮，最右边的垃圾桶图标就是「删除回复」。
2. 点击后确认删除：这条回答会从本机移除，你的提问会保留。
3. 删除后提问下方会出现「重新生成回复」按钮，点一下就能重新回答。
4. 如果这条回答有多个版本，删除当前版本会自动切到另一个版本；全部删掉后同样可以重新生成。
5. 删除不可撤销，只影响当前对话，不影响其他会话。

六、帮我回一句（角色扮演续写，1.4.0 新增）
1. 当最后一条是 AI 回复、输入框还是空的时候，输入框上方会出现「✦ 帮我回一句」。
2. 点一下，应用会读最近的对话，用「我」的身份写一条接下来的回复，用来推进剧情。
3. 弹窗里可以直接改；点「换一句」换一个走向，点「填入输入框」放回输入框。
4. 填入后可以继续修改，再点发送，剧情就接下去了。
5. 生成会调用一次模型（按你设置的接口地址计费），不会写进对话记录。
6. 输入框里有文字或正在生成回复时，这个按钮会隐藏。

七、让剧情继续（1.5.0 新增）
1. 输入框上方、和「帮我回一句」并排的「» 让剧情继续」。
2. 点一下，AI 会直接往下写：描写接下来发生的事、环境和对方的反应，不替你行动。
3. 对话里会出现一个「剧情继续」的小标记，然后接一段新的剧情，不需要你先说话。
4. 可以连续点，让剧情一段段往下走；随时也可以自己插话。
5. 这条导演指令会保存在本机并参与后续上下文；删掉对应的回复后可以重新生成。

八、自动折叠思考过程（1.6.0 新增）
1. 设置 → 通用设置 → 「自动折叠思考过程」开关。
2. 打开后：深度思考生成时先展开，回答结束后自动收起，只留「已思考（用时 N 秒）」标题。
3. 点标题可以随时展开/收起；手动点过之后，这条消息不再自动跟随。
4. 关闭开关：思考过程默认展开，和以前一样。
5. 设置保存在本机，重启应用后保持。

九、头像（1.7.0 新增）
1. 设置 → 通用设置：
   - 「显示头像」开关：控制对话里是否显示头像。
   - 「我的头像」「AI 头像」：点圆形预览上传图片，也可以更换或移除。
2. 上传的图片会压缩成 160×160 保存在本机，不会上传到服务器。
3. 打开开关后：你的消息右侧显示你的头像，AI 回复左侧显示 AI 头像；
   没设置图片时显示「我」「AI」占位。
4. 关闭开关就恢复原来的纯文字布局，已上传的头像会保留。

十、检查更新（1.8.0 新增）
1. 设置 → 通用设置 → 最下面的「版本与更新」，显示当前版本。
2. 点「检查更新」，会读取 GitHub 仓库的最新 Release：
   https://github.com/98893566/deepseek-chat-android
3. 有新版本会弹窗显示版本号和更新说明，点「下载更新」打开 APK 下载页，
   下载后覆盖安装即可。
4. 连不上 GitHub 时会提示，可让对方直接发 APK。
5. 覆盖安装仍要求同一签名，签名不同的包要先卸载（会清空本地对话）。

十一、导入 DeepSeek 历史对话
1. 先到 chat.deepseek.com 网页版：设置 → 数据管理 → 导出所有历史对话，
   下载 deepseek_data-*.zip。
2. 本应用：设置 → 数据管理 → 导入历史对话 → 上传 → 选择这个 ZIP。
3. 默认勾选「保留现有对话（合并导入）：导入的会话追加到列表，本地原有对话和附件保留。
4. 取消勾选会变成「覆盖导入」：清空本地全部对话和附件，无法撤销，建议先导出备份。
5. 1.8.0 及更早版本的导入是覆盖式；如果当时没有先导出，旧对话无法找回。

十二、已保留的功能
- 流式回答、深度思考、联网搜索与来源引用
- 多会话、重新生成、编辑提问、消息分支
- 图片/文件附件、语音输入、回复朗读
- Markdown、代码高亮、公式、Mermaid 图
- 深浅色主题、中英文界面
- 历史导入/导出（导出的 ZIP 保存在「下载/DeepSeek」）

十三、注意
- 语音输入第一次使用会请求麦克风权限。
- 联网搜索、语音等能力依赖服务端支持，部分中转站可能只支持纯对话。
- 卸载应用会删除本地对话；重要记录请先在“设置”里导出。
- 升级必须使用同一签名，直接覆盖安装即可。

十四、常见问题
- 白屏或打不开：确认手机联网后重开。
- 提示 401 / API Key 无效：检查中转站的 Key 是否填对。
- 提示 404：接口地址不对，或中转站不支持 Anthropic 接口；试试加 /v1 或 /anthropic。
- 提示网络错误：中转站没有允许跨域（CORS），或地址不可访问。
- 压缩按钮是灰的：需要至少 2 轮完整对话，或正在生成回复。
- 删除了回答想恢复：回答内容已移除，点提问下的「重新生成回复」让模型重新答一次。
- 看不到「帮我回一句 / 让剧情继续」：输入框里有文字、正在生成回复，或最后一条不是 AI 回复时会隐藏。
- 换手机：旧机“导出全部会话”，把 ZIP 拷到新机后导入。
